## COMPILATION

To compile the code navigate the terminal to the BICI directory and enter:

make

## RUN

The core BICI code is run using the command:

mpirun -n [# core] ./bici-para [dir/file.bici] [operation]

where:

[# core] = The number of cores used to execute the code (this will typically be the number of MCMC chains or PAS-MCMC particles). Note, when running on a single core "mpirun -n [# core]" can be omitted. 

[dir/file.bici] = The path and BICI-script file that describes the model and (potentially) data.

[operation] = The mode of operation, selected from the following options:

Note, on some operating systems its necessary to 'load module load mpi/openmpi-x86_64'.

### Main operations:

	sim / simulate - This simulates from the model.
		E.g. ./bici-para dir/file.bici sim
	
	inf / inference - This performs inference from the model and data.
		E.g. ./bici-para dir/file.bici inf
	
	post-sim / posterior-simulation - Generates a posterior simulation (note, inference needs to first be performed). 
		E.g. ./bici-para dir/file.bici post-sim
	
	ext / extend - Extends inference (useful when MCMC is yet to converge).
		E.g. ./bici-para dir/file.bici ext 200%             (this doubles the number of MCMC updates)
		E.g. ./bici-para dir/file.bici ext 10000            (this extends the number of MCMC updates to 10000)

### Data operations:

	data-sim - Simulates data (note, simulation needs to first be performed).
		E.g. ./bici-para dir/file.bici data-sim 'ic' 'pop-data name="pop" filter="DS=file" dt=10 error="poisson"'
		This example simulates the initial conditions and time-series population data (measured every 10 time units using a Poisson observation error model). See Appendix L in the manual for further details.
		
	data-show - This shows all data sources within the BICI-script.
		E.g. ./bici-para dir/file.bici data-show
	
	data-del - This deletes data sources within the BICI-script.	
		E.g. ./bici-para dir/file.bici data-del             (deletes all data sources).
		E.g. ./bici-para dir/file.bici data-del 1           (deletes data source 1, where number comes from 'data-show' above).
		E.g. ./bici-para dir/file.bici data-del 'Genetic'   (deletes data source with name beginning with 'Genetic').
	
	clear - Deletes any parameter or state samples generated by BICI.
		E.g. ./bici-para dir/file.bici clear             		(deletes all parameter and state information).
		E.g. ./bici-para dir/file.bici clear all         		(deletes all parameter and state information).
		E.g. ./bici-para dir/file.bici clear sim            (deletes just simulated parameter and state information).
		E.g. ./bici-para dir/file.bici clear inf            (deletes just inferred parameter and state information).
		E.g. ./bici-para dir/file.bici clear post-sim    		(deletes just posterior simulated parameter and state information).

### Compression operations:

	comp / compress - Compresses the contents within files (to reduce memory consumption).
		E.g. ./bici-para dir/file.bici compress   

	decomp / decompress - Decompresses the contents within files (for readability).
		E.g. ./bici-para dir/file.bici decompress   
	
### Validation operations:

	tornado - Generates scripts used to create a tornado plot (used for validation, see Appendix M of the manual for details).
		E.g. ./bici-para dir/file.bici tornado 'ic' 'pop-data name="pop" filter="DS=file" dt=10 error="poisson"'
	
	tornado-res - Once the scripts from 'tornado' have been run, this collates the results.
		E.g. ./bici-para dir/file.bici tornado-res
	
	scan - Generates scripts used to create a tornado plot (used for validation, see Appendix M of the manual for details).
		E.g. ./bici-para dir/file.bici scan:'\beta range=0.0005,0.002 n=20 log=false' 'ic' 'pop-data name="pop" filter="DS=file" dt=10 error="poisson"'
	
	scan-res - Once the scripts from 'scan' have been run, this collates the results.
		E.g. ./bici-para dir/file.bici scan-res:'\beta’

## MODIFICATION 

Various modification can be made on the command line:

	-op="file-op.bici" / -output="file-op.bici"  Sets the output file (by default outputs are placed into the input file).
	-seed=100                                    This overrides seed set in the BICI-script.
	-sim=1                                       Selects a particular simulation when creating data (using 'data-sim' above).
	-co=0 / -core=0                              Runs a specified core (used when running core code from the interface).
	-samp=0                                      Sets how sampling is done (for diagnostic purposes only).
	
    E.g. ./bici-para -seed=100 [dir/file.bici] [operation]
